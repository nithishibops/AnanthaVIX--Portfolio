# Ananthavix Solutions — redesigned website

A responsive, static website with a navy, white and cyan design. Includes the supplied Ananthavix logo, all original business sections, a privacy page and an accessible enquiry dialog.

## Open locally
Open `index.html` in a browser. No installation or build step is required. Google Fonts needs internet access; system fonts are used when unavailable.

## Publish on Vercel
1. Extract this ZIP.
2. Upload its contents to your GitHub repository with `index.html` at the repository root.
3. Import the repository in Vercel.
4. Select **Other** as the framework. No build command is needed; use the repository root as the output directory.
5. Deploy.

For an existing repository, replace the website files with this ZIP's contents. No credentials or server configuration are needed.
