- **Automation work** — Excel/VBA consolidation, file conversion, mail-merge document generation and data formatting (described publicly without source files)

## Publish with GitHub Pages

1. Create or open your Ananthavix GitHub repository.
2. Upload everything in this folder to the repository root.
3. Commit the files.
4. Open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select the `main` branch and `/ (root)`.
7. Save.

The website is plain HTML/CSS/JavaScript, so no build command is required.

## Privacy approach

- Personal portfolio links are intentionally not published on the Ananthavix website.
- Dashboard repositories, automation source files and HRMS source code are not linked publicly.
- Public visitors see professional project summaries only.
- Memora remains linked to Google Play because it is a public released product.
- Detailed demonstrations can be provided privately to genuine prospects when appropriate.
